# Portfolio demo data

Committed as ordinary (non-LFS) gzip-compressed CSVs (`pandas.read_csv`/`to_csv` handle `.csv.gz` transparently on Windows, Linux, and macOS, no extra tooling needed), so a normal `git clone` gets the real files directly. Generated by `data_portfolio_allocation.ipynb`, which only re-downloads from Yahoo Finance for a file that's missing; delete a file here and rerun that notebook to refresh it. `checksums.txt` records each committed file's SHA-256 as of the commit that added it, for verifying a copy obtained some other way. The 4-, 10-, and 20-asset universes are the first 4, 10, and 20 tickers in the canonical 40-asset snapshot.

The canonical daily log returns (`log_returns40_2014-01-01_to_2026-09-30.csv.gz`) are not committed: they are derived from the price file, written here by `data_portfolio_allocation.ipynb`, and rebuilt by `portfolio_allocation_demo.ipynb` (via `backtest_util.load_log_returns`) if missing, with no download. The smaller return matrices are sliced from this cache.

| File | Description |
|---|---|
| [`df40_2014-01-01_to_2026-09-30.csv.gz`](df40_2014-01-01_to_2026-09-30.csv.gz) | Canonical daily adjusted prices and trading volumes for all 40 assets; smaller universes are sliced from this file. |
| `log_returns40_2014-01-01_to_2026-09-30.csv.gz` (gitignored) | Daily log returns derived from the canonical price file; smaller universes are sliced from this cache. |
| [`market_2014-01-01_to_2026-09-30.csv.gz`](market_2014-01-01_to_2026-09-30.csv.gz) | Daily `sp500_price` (S&P 500 total return, ^SP500TR closing price, the passive buy-and-hold benchmark) and `rf_annual` (annualized log risk-free rate derived from 13-week U.S. Treasury bill data), joined on `Date`; a date missing from one series is empty in its column. |
